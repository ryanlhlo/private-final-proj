About Project Gutenberg

Project Gutenberg offers 75,000+ free eBooks. No registration, no fees, no ads. Preserving literature for everyone, forever.

Started in 1971 by Michael Hart. First eBook: U.S. Declaration of Independence. Now run by 50,000+ volunteers worldwide.

Proofreaders, formatters, programmers. Anyone can help at PG Distributed Proofreaders.

All books are public domain (copyright expired). Plain text, HTML, EPUB, Kindle. Use freely but attribute source.
